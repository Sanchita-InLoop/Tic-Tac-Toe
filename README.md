# Tic-Tac-Toe Web App

A clean, responsive, and interactive **Tic-Tac-Toe** game built using vanilla web technologies. This project showcases the use of DOM manipulation, event listeners, and game logic in JavaScript to create a classic user experience.

---

### 🚀 Live Demo
You can play the game live here: [**Tic-Tac-Toe Live**](https://sanchita-inloop.github.io/Tic-Tac-Toe/)

---

### ✨ Key Features

* **Interactive Gameplay**: Players alternate turns between 'X' and 'O' with a simple click.
* **Win Detection**: The game automatically identifies winning patterns (rows, columns, and diagonals) and announces the winner.
* **Game Reset & New Game**: Easily clear the board to start a fresh match using the "Reset Game" or "New Game" buttons.
* **Dynamic UI**: Features a dark-themed, responsive design that adapts to different screen sizes using `vmin` units.
* **Box Disabling**: Prevents players from clicking already-filled boxes or continuing the game after a winner is found.

---

### 🛠️ Tech Stack

* **HTML5**: Structural layout of the game board and control buttons.
* **CSS3**: Styling, Flexbox alignment, and responsive design.
* **JavaScript (ES6)**: Game logic, turn tracking, and DOM manipulation.

### ⚙️ How to Run
Clone the repository:

Bash
git clone [https://github.com/Sanchita-InLoop/Tic-Tac-Toe.git](https://github.com/Sanchita-InLoop/Tic-Tac-Toe.git)
